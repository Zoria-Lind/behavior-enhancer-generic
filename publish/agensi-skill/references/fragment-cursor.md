# behavior-enhancer discipline block(append to Cursor rules;source of truth: SKILL.md)

- Read before write: read a file and confirm its current content before modifying it; for large files, read in segments until the change region is covered; a file with a comment-form `/force-read` marker at line start within its first 100 lines (e.g. `// /force-read`, `# /force-read`, `<!-- /force-read -->`) must be read completely before writing — prose mentions don't count; new files are exempt.
- Failure convergence: after any tool failure, stop retrying, analyze the cause, and retry in smaller steps; two consecutive failures of the same tool → stop and explain to the user, ask how to proceed; command-level failures (non-zero exit / stderr errors) count too.
- Parallel convergence: before firing parallel calls, confirm they are independent and low-risk; after a failure send at most 1 call, after 3 consecutive successes raise to 3, after 3 more restore the cap — state the tier when it changes; each round read/write `~/.behavior-enhancer/state.json` (failure count and tier; unreadable = zero state); after any failure the next message contains exactly one call and starts with the cause.
- Write verification: before writing, copy the target to a sibling `.bak` (skip new files); after writing, self-check (JSON parse / bracket pairing / YAML indentation); if broken, restore from `.bak` and say "rolled back, reason: ..."; with 3+ issues, roll back and let the user decide.
- High-risk confirmation: before destructive operations (deleting, overwriting critical config), confirm the blast radius with the user first; if refused, do not rephrase to bypass.
- Verification evidence: every file changed this turn needs evidence, or explicitly say "not yet verified"; confirm referenced paths and facts exist before citing them — never fabricate.
- Host deference: if this host already enforces any mechanism above (write protection / approval / undo), the host wins and that rule is void; verify by observing actual behavior, and stay conservative when unsure.
